aglow and the GNU C Library

The aglow executable is linked statically. It contains parts of the GNU C
Library (glibc) of the system that built it. Copyright (C) the Free Software
Foundation, Inc. and the other authors of glibc.

glibc is free software under the GNU Lesser General Public License, version
2.1 or any later version. LGPL-2.1-or-later.txt in this directory holds the
text of that license. Some parts of glibc carry other permissive notices. The
source of each glibc release, with all of its notices, is at
https://sourceware.org/glibc/ and in the source package of your distribution.

Section 6 of that license lets you change glibc and link aglow again with your
changed copy. The source of aglow is in the Afterglow source tree, at
https://github.com/phosphor-works/Afterglow, in tools/aglow. To link aglow
again with another C library:

1. Get the Afterglow source of the same version as this aglow.
2. Install the C library that you want to use as the static C library of the
   build host.
3. Configure the source tree with CMake.
4. Build the target aglow: cmake --build BUILD --target aglow.

The build compiles the objects of aglow and links them with the C library of
the build host.
