aglow and the GCC runtime libraries

The aglow executable is linked statically. It contains parts of the GNU C++
library (libstdc++) and of the GCC support library (libgcc) of the system that
built it. Copyright (C) the Free Software Foundation, Inc.

version 3.1. GPL-3.0-or-later.txt in this directory holds the text of that
license. The exception lets a program contain these parts under the terms of
the program's own license. The text of the exception follows.
